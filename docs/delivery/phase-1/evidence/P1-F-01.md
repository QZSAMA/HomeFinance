## 实施结果

- `Family.timezone` 是 `VARCHAR(64) NOT NULL DEFAULT 'Asia/Shanghai'`；创建 API 接受规范化的 IANA 时区，省略字段默认上海，显式非法值返回 `400 INVALID_TIMEZONE`。
- `PUT /api/families/:id` 只要请求自有 `timezone` 属性即返回 `409 FAMILY_TIMEZONE_IMMUTABLE`，且在任何 update 调用前结束；GET 列表/详情通过 Prisma 标量返回时区。
- 迁移 `20260903100000_add_family_timezone` 为既有家庭回填上海、增加非空内容约束，并建立 `BEFORE UPDATE OF timezone` 触发器；直接 SQL 修改会回滚并抛出 `FAMILY_TIMEZONE_IMMUTABLE`。
- `resolvePeriodWindow` 是无副作用纯服务，按家庭时区生成 `[startUtc, endUtc)`，支持 `CUSTOM`、`MONTHLY`、`QUARTERLY`、`YEARLY`，并处理闰年与 DST，不读取进程/浏览器本地时区。
