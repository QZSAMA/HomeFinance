### V3.1.2 安全加固

#### 密码安全

**问题**：无密码强度要求，无登录失败保护。

**方案**：
- 注册/修改密码时校验强度：最少 8 位，含大小写字母 + 数字
- 登录失败 5 次锁定该账号 15 分钟（Redis 计数 + TTL）
- 新增 `POST /api/auth/change-password` 接口

**测试**：
- 单元：弱密码拒绝（< 8 位、无大写、无数字）
- 集成：连续 5 次错误登录 → 第 6 次返回 423 LOCKED
- 集成：锁定 15 分钟后可正常登录

#### AI Prompt 注入防护

**问题**：用户输入直接拼入 AI prompt，存在注入风险。

**方案**：
- sanitize 函数：移除 `<|system|>`、`<|user|>`、`<|assistant|>` 等角色标记
- 限制用户单次输入长度（2000 字符）
- 系统提示词与用户输入严格分离（system / user 消息分开发送）

**测试**：
- 单元：含角色标记的输入被正确清理
- 单元：超长输入被截断或拒绝

#### 文件上传安全

**问题**：只信任扩展名，未校验文件实际类型。

**方案**：
- MIME 白名单：`image/jpeg`、`image/png`、`image/webp`
- 文件头 magic number 校验（读取前几字节判断真实类型）
- 拒绝非图片文件

**测试**：
- 单元：伪造扩展名的文件被拒绝（.jpg 但实际是 .exe）
- 集成：正常图片上传成功

### V3.1.3 健康检查 + 结构化日志

#### 健康检查端点

**方案**：
- `GET /api/health`：检查 PostgreSQL / Redis / MinIO 连接状态
- 返回 `{ status: "ok"|"degraded", services: { db: "up", redis: "up", minio: "up" } }`
- 不需要认证

**测试**：
- 集成：所有服务正常时返回 200 + ok
- 集成：Redis 宕机时返回 503 + degraded

#### 结构化日志

**方案**：
- JSON 格式日志：`{ timestamp, level, requestId, module, message, ...meta }`
- 请求追踪中间件：每个请求分配 `requestId`（UUID），注入到 `req` 和响应头 `X-Request-Id`
- 日志级别：`error` / `warn` / `info` / `debug`

**测试**：
- 集成：请求返回 `X-Request-Id` 头
- 集成：日志输出包含 requestId 字段

### V3.1.6 AI 成本控制

**问题**：用户可无限制调用 AI，成本不可控，无降级策略。

#### 配额限制

**方案**：
- 每用户每日 AI 调用配额（默认 50 次/天，可配置）
- Redis 计数：`ai:quota:{userId}:{date}`，TTL 到当日 23:59:59
- 超额返回 429 + 提示信息

**测试**：
- 单元：配额计数正确递增
- 集成：第 51 次调用返回 429

#### 降级策略

**方案**：
- AI 服务超时/报错时，返回友好提示而非 500 错误
- OCR 失败时返回原始文本（已有降级，需确认）
- 响应中增加 `aiConfigured` 和 `aiAvailable` 字段

**测试**：
- 单元：AI 服务 mock 报错 → 返回降级提示
- 集成：AI 不可用时 `/api/health` 标记 `ai: "down"`

#### AI 调用日志

**方案**：
- 记录每次 AI 调用：userId、familyId、type、tokenUsage、latency、success
- 存入 `AiCallLog` 表（新 Prisma model）

**测试**：
- 集成：AI 调用后在 AiCallLog 表有记录

## 数据模型变更

### 新增 AiCallLog

```prisma
model AiCallLog {
  id          String   @id @default(cuid())
  userId      String
  familyId    String?
  type        String   // "chat" | "ocr" | "category"
  model       String?
  tokenUsage  Int?
  latency     Int?     // ms
  success     Boolean
  error       String?
  createdAt   DateTime @default(now())

  @@index([userId])
  @@index([createdAt])
}
```

### User 表新增字段（可选）

```prisma
model User {
  // ... 现有字段
  aiQuotaOverride Int?    // 自定义配额，null 时用默认值
}
```
